A minimal scripting language for Unix.

# types are required, blocks use indentation x:int = 5 + 3 immut name:str = "glape" loop i in 1..=3: print(i)

Why Glape

Most scripting languages carry decades of legacy. Glape starts from nothing — a small binary, a bytecode VM, a library system that distributes compiled binaries, and direct FFI to C without an interpreter layer in between.

It is designed for automation scripts that run often, load fast, and stay out of the way.

Get started

Build from source:

git clone https://github.com/greqx/glape && cd glape && make

Requires GCC and GNU Make.
